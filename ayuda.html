GENERAR ALTAS NUEVAS

Procedimiento de carga y emisión de lote de titulares nuevos
Lote ALTAUSUCBPRE.782
  1. Subir el archivo Altas.xlsx.
  2. Menu - Beneficiarios - Procesar Excel (Altas.xls)
  3. El mismo posee el siguiente formato
    Apellido-Nombre-Domicilio-Calle Domicilio-Numero Domicilio-Piso Domicilio-Departamento-Localidad-Provincia-Sexo-Codigo-Postal-Telefono Caracteristica-Telefono Numero-Estado Civil-Fecha Nacimiento-Tipo Documento-Numero Documento-Prov. Documento-CUIT/CUIL
  4. Respetando el Formato del Anexo 1 - Novedades de Altas de Tarjetas Precargadas Del Manual Cabal
  5. Menu - Beneficiarios Generar ALTAUSUCBPRE
  6. Copiar los datos generados en pantalla a un archivo de texto (notepad++) y agregar un salto de linea al final. Debe de hacerce en windows ya que son diferentes los archivos generados entre Linux/Windows.
  7. Subir ese archivo a la plataforma de cabal con el nombre ALTAUSUCBPRE.782
  8. La plataforma responde con un archivo del tipo 782_out_altas_tpc_202207XX_XXXX_XXXXXX Que se procesa en el siguiente paso

PROCESAR NOV. ALTAS

Asignación de cuentas y tarjetas devueltas por el banco
Devolución Banco
  1. En este archivo se encuentran los datos de la nueva tarjeta, incluyendo Numero Cuenta y Numero Tarjeta
  2. Descargar desde plataforma el archivo 782_out_altas_tpc_202207XX_XXXX_XXXXXX
  3. Renombrar el mismo a MovAltas.txt
  4. Subir el archivo MovAltas.txt
  5. Menu - Beneficiarios - Procesar MovAltas.txt (Dev. Banco)
  6. Se cargan los beneficiarios en la BD, se debe de exportar desde phpmyadmin a excel.

GENERAR ACREDITACIONES DE SALDO (Este archivo con este formato lo envian desde Suministros con pequeños cambios)

Generación y control del lote de carga NOVCAR.782
Lote NOVCAR.782
  1. Modificacr y Generar el archivo Acreditaciones.xlsx
  2. El Mismo debe de Tener el siguiente formato
    Id-Apellido-Nombre-Localidad-DNI-CUIT-Monto a Acreditar
  3. Subir el archivo Acreditaciones.xlsx - En el formato de abajo, no lleva el total en la ultima fila
    4. Estructura del archivo de Acreditaciones
  4. ASI ES EL ARCHIVO FINAL
    5. Captura de muestra: Columnas y filas del archivo final sin totales
  5. Menu - Acreditaciones - Procesar Excel (Acreditaciones.xlsx)
  6. Menu - Acreditaciones - Generar NOVCAR
  7. Copiar los datos generados en pantalla a un archivo de texto (notepad++) y agregar un salto de linea al final. Debe de hacerce en windows ya que son diferentes los archivos generados entre Linux/Windows.
  8. Subir ese archivo a la plataforma de cabal con el nombre NOVCAR.782
  9. La plataforma responde con un archivo del tipo 782_RCAR_20220731_1841_324794.txt Que se procesa en Procesar Respuesta Acreditaciones

PROCESAR RESPUESTA DE ACREDITACIONES

Confirmación de acreditación efectiva en cuentas
Archivo RCAR
  1. Descargar desde Plataforma Archivo del tipo 782_RCAR_20220731_1841_324794.txt
  2. Este archivo se el dia que se realiza la acreditacion en las cuentas de los beneficiarios
  3. Renombarar el archivo descargado a RespuestaCargas.txt
  4. Subir el archivo RespuestaCargas.txt
  5. Menu - Procesar RespuestaCargas.txt (Dev. Banco)
  6. se Mostrara en Pantalla las Cargas de Credito Realizadas

PROCESAR MOVIMIENTO DE CUENTAS

Liquidación mensual de compras, extracciones y autorizaciones
Mensual
  1. Descargar desde Plataforma Archivo del tipo 782_Nacion_20220731_1841_324794.txt
  2. Este archivo se sube a la misma El ultimo dia Habil de Cada Mes (o El 1er Dia Del Mes Siguiente
  3. Renombrar el archivo descargado a Movimientos.txt
  4. Subir el archivo Movimientos.txt
  5. Menu - Movimientos - Procesar Movimientos.txt
  6. Seleccionar el Mes al que corresponden los movimientos
  7. Si el mes seleccionado ya esta cargado, genera un mensaje de error y no permite nuevamente la carga
  8. Se graban los datos a la tabla movimientos, exportar la misma a CSV For Ms excel

Débito de fondos y reverso de saldos remanentes
Débito
