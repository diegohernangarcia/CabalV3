GENERAR ALTAS NUEVAS
  1. Subir el archivo ALTAS.xlsx.
  2. Menu - Cargar Altas Excel.
  3. El mismo posee el siguiente formato
  4. Apellido-Nombre-Domicilio-Calle Domicilio-Numero Domicilio-Piso Domicilio-Departamento-Localidad-Provincia-Sexo-Codigo-Postal-Telefono Caracteristica-Telefono Numero-Estado Civil-Fecha Nacimiento-Tipo Documento-Numero Documento-Prov. Documento-CUIT/CUIL
  5. Respetando el Formato del Anexo 1 - Novedades de Altas de Tarjetas Precargadas Del Manual Cabal
  6. Menu - Generar ALTAUSUCBPRE.
  7. Copiar los datos generados en pantalla a un archivo de texto (notepad++) y agregar un salto de linea al final. Debe de hacerce en windows ya que son diferentes los archivos generados entre Linux/Windows.
  8. Subir ese archivo a la plataforma de cabal con el nombre ALTAUSUCBPRE.782
  9. La plataforma responde con un archivo del tipo 782_out_altas_tpc_202207XX_XXXX_XXXXXX

PROCESAR NOV. ALTAS
  1. En este archivo se encuentran los datos de la nueva tarjeta, incluyendo Numero Cuenta y Numero Tarjeta
  2. Descargar desde plataforma el archivo 782_out_altas_tpc_202207XX_XXXX_XXXXXX
  3. Renombrar el mismo a MovAltas.txt
  4. Subir el archivo MovAltas.txt
  5. Menu - PROCESAR NOV. ALTAS
  6. Se cargan los beneficiarios en la BD, se debe de exportar desde phpmyadmin a excel.
    GENERAR ACREDITACIONES DE SALDO (Este archivo con este formato lo envian desde Suministros con pequeños cambios)
    1. General el archivo Acreditaciones.xlsx
    2. El Mismo debe de Tener el siguiente formato
    3. Id-Apellido-Nombre-Localidad-DNI-CUIT-Monto a Acreditar
    4. Subir el archivo Acreditaciones.xlsx - En el formato de abajo, no lleva el total en la ultima fila
    5. ASI ES EL ARCHIVO FINAL
    6. Menu - Acreditar Saldo 3
    7. Menu - Generar NOVCAR
    8. Copiar los datos generados en pantalla a un archivo de texto (notepad++) y agregar un salto de linea al final. Debe de hacerce en windows ya que son diferentes los archivos generados entre Linux/Windows.
    9. Subir ese archivo a la plataforma de cabal con el nombre NOVCAR.782
    PROCESAR MOVIMIENTO DE CUENTAS
    1. Descargar desde Plataforma Archivo del tipo 782_Nacion_20220731_1841_324794.txt
    2. Este archivo se sube a la misma El ultimo dia Habil de Cada Mes (o El 1er Dia Del Mes Siguiente
    3. Renombarar el archivo descargado a Movimientos.txt
    4. Subir el archivo Movimientos.txt
    5. Menu - Procesar Movimientos
    6. Seleccionar el Mes al que corresponden los movimientos
    7. Si el mes seleccionado ya esta cargado, genera un mensaje de error y no permite nuevamente la carga
    8. Se graban los datos a la tabla movimientos, exportar la misma a CSV For Ms excel
    PROCESAR RESPUESTA DE ACREDITACIONES
    1. Descargar desde Plataforma Archivo del tipo 782_RCAR_20220731_1841_324794.txt
    2. Este archivo se el dia que se realiza la acreditacion en las cuentas de los beneficiarios
    3. Renombarar el archivo descargado a RespuestaCargas.txt
    4. Subir el archivo RespuestaCargas.txt
    5. Menu - PROCESAR CARGA CREDITO
    6. se Mostrara en Pantalla las Cargas de Credito Realizadas
